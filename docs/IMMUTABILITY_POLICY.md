# Immutability Policy

G1→G12 are read-only historical evidence.

The original G1 through G12 release ZIPs in the Forensic Freeze must never be rewritten, replaced, or silently corrected. Future work must be additive and versioned.

If an error or documentary defect is discovered, record it in a later artifact with an explicit reference to the affected historical object. Do not mutate the historical bytes.
