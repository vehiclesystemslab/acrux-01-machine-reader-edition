# PROVENANCE LIMITS

1. SHA-256 verifies byte identity relative to a trusted fingerprint; it does not by itself prove authorship or creation time.
2. G1-G9 did not originally embed previous-release ZIP hashes. This freeze records the retained artifacts retrospectively and proves their payload continuity by direct byte hashing.
3. G10-G12 parent-release SHA-256 fields are intrinsic to those manifests and match the retained preceding ZIPs.
4. The canonical human-language source was verified during freeze construction but is intentionally omitted from this package.
5. No claim is made that future AI systems must obey the reader directive; it is a normative conformance and rights statement.
6. This forensic package must never be used as a reason to mutate the historical G1-G12 ZIPs. Corrections are additive, versioned evidence.
